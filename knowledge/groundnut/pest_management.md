# TNAU Groundnut Red Hairy Caterpillar
Source URL: https://agritech.tnau.ac.in/crop_protection/groundnut/crop_prot_crop_insect_oil_ground%20nut_1.html
Source Organization: Tamil Nadu Agricultural University (TNAU)
Topics: pest management, diagnosis

TNAU describes red hairy caterpillar damage as crop defoliation, potentially leaving the main stem. Its management page includes non-chemical practices such as locating and destroying pupae before summer rains, monitoring moth emergence, collecting egg masses and early larvae, and preventing larval movement from infested fields. The source contains additional control details; check the current page and local extension recommendations before use.
