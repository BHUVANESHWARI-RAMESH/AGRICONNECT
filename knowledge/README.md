# Local Agricultural Knowledge Sources

The crop folders contain concise searchable notes based on the TNAU pages linked inside each document. Each note records its title, crop, topic, and original source URL. The notes are short summaries, not a replacement for the original TNAU material.

Put additional `.md`, `.txt`, or text-based `.pdf` documents inside the appropriate crop folder. Run `python rag_knowledge_base.py ingest` to rebuild the local vector database from these files.
